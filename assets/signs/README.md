# Reference photos

Add one photo per letter, named by the letter: `A.jpg`, `B.jpg`, ... `Y.jpg`.
The game shows the photo under the target letter if it exists, and hides the
space if it doesn't.

Tips: take them of a teammate's hand against a plain background, crop to
square, and keep each under 200 KB. Taking your own photos keeps the project
"built from scratch" and avoids image licensing questions.
